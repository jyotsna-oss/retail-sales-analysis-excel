# 📊 Retail Sales Analysis — Excel

**An Excel portfolio project exploring retail sales performance, product revenue and monthly trends.**

---

## 🎯 Project Objective

To analyse a fictional retail sales dataset and identify:
- The highest-revenue product
- The best-performing region
- Monthly sales trends

## 🛠️ Tools & Skills

- Microsoft Excel
- Data cleaning and formatting
- PivotTables and PivotCharts
- Dashboard creation
- Business insights and recommendations

## 📈 Key Findings

| Analysis | Finding | Revenue |
|---|---|---:|
| Top Product | Backpack | £3,444.00 |
| Top Region | West | £2,783.66 |
| Highest Month | November | £1,397.80 |
| Lowest Month | December | £299.00 |

## 💡 Business Recommendation

Investigate the factors behind November's strong revenue and review December's lower performance to identify potential opportunities for improvement.

## 📁 Project File

- `Retail_Sales_Analysis_Portfolio.xlsx` — Excel workbook containing the analysis, PivotTables, PivotCharts and interactive dashboard.

This is a practice portfolio project using fictional retail sales data.
